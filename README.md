# 🛍️ Handcraft E-Commerce Website

A full-stack e-commerce web application developed for selling handmade and handcrafted products online.

The application allows users to browse products, manage their shopping cart, place orders, make payments, generate invoices, and provide product reviews. It also includes an admin dashboard for managing products, customers, categories, and orders.

## 🚀 Features

### 👤 User Features

- User Registration and Login
- Secure Password Hashing
- User Profile
- Browse Products
- Product Categories
- Product Details
- Add to Cart
- Update Cart Quantity
- Remove Products from Cart
- Checkout
- Order Management
- Order History
- Invoice Generation
- Product Ratings and Reviews
- Email Notifications

### 👨‍💼 Admin Features

- Admin Login
- Admin Dashboard
- Customer Management
- Product Management
- Category Management
- Order Management
- View Customer Orders

### 💳 Payment Features

- Cash on Delivery
- Online Payment
- Payment Status Tracking
